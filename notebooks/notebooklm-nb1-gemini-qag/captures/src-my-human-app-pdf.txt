The Master Reagent Prompt
Copy and paste the block below directly into your Al coding assistant or Antigravity workspace
initialization.
# SYSTEM DIRECTIVE: INITIALIZE PROJECT "MY HUMAN"
## PROJECT OVERVIEW
You are acting as the lead full-stack engineering agent for "My Human"-a social connectivity,
self-care, and philosophy application. The core ethos is low-stress, high-resonance, and
absolute user privacy. The UI must be sleek, eye-catching, yet fundamentally soothing.
## TECH STACK SPECIFICATIONS
***Frontend Web/Portal:** React via Vite.
***Styling:** Tailwind CSS with framer-motion for fluid, slow-easing animations.
***Native Mobile (Future Bridge):** Kotlin with local NPU execution via LiteRT (for Gemma 4
integration).
***Backend/API:** Go or Python (Express/FastAPI for web bridging).
***Data Structure:** Lightweight JSON for "Daily Nuggets" and localized resource API hooks.
## UI/UX DESIGN LANGUAGE (STRICT ENFORCEMENT)
***Theme:** Default to a deep, OLED-friendly Dark Mode (Primary BG: `#0B0F19`).
***Accents:** Bioluminescent blues, soft violets, and warm gold for interactive elements.
***Cards & Containers:** Utilize glassmorphism (translucent backgrounds with blur
`backdrop-blur-md`) with subtle, 1px white borders at 10% opacity.
***Typography:** Sans-serif, highly legible fonts (e.g., Inter or Roboto) with generous line
spacing. No dense blocks of text.
***Interactions:** Remove standard "Like" or "Share" icons. Replace with a minimal "Resonate"
icon (e.g., a concentric wave or subtle spark). All hover states should ease in over 0.3s.
## PHASE 1: GENERATE SCAFFOLDING
Execute the following build sequence:
1. **Initialize the Vite/React Environment:** Set up the basic routing structure (Home/Nuggets,
The Pool, The Al Companion).
2. **Build the "Daily Nugget" Component:** Create a full-width, sleek card component that
displays a short philosophical quote, a subtle background image gradient, and a "Save to My
Human" interaction button.
3. **Build "The Pool" (Community Board) Component:** A scrolling feed of text-based posts.
Ensure the Ul feels like a quiet forum, prioritizing readability over engagement metrics (hide
timestamps and follower counts).
4. **Construct the Al Chat Interface:** Design a dedicated messaging screen for the Gemma 4
companion. Use soft chat bubbles. Include a silent background function that scans inputs for
emergency keywords to gracefully render local support resources in-line.
## EXECUTION COMMAND
Begin by generating the file structure, the `package.json' dependencies, and the App.jsx
routing map based on the specifications above. Do not use dummy code; provide full, functional
React components.
Specific Module Instructions for You
As the agent begins spitting out the code, you'll want to guide it through the specific mechanics
of the backend. Here are the exact parameters to keep in mind when refining the code:
•
The Al Companion Logic: When setting up the backend logic for the Al, specifically
instruct your IDE to structure the API calls so they can eventually be swapped out for
local on-device inference. You want the React frontend to easily talk to your Kotlin/LiteRT
Android build down the line.
The Resource Router (Invisible Safety Net): Have the agent create a
safety_net_utils.js file. Instruct it to build a function that takes a string input (the
user's chat message), checks it against an array of heavy emotional keywords, and
returns a localized JSON object of resources (like Calcutta/Salineville community
centers) if a threshold is met.
• The Content Engine: Create a simple nuggets.json file in your source directory to
start holding those philosophical quotes and ideas. The UI can map over this file to
generate the daily feed, allowing you to easily add new quotes without touching the
frontend code.
This structure gives your IDE exact boundaries, forcing it to write clean, intentional code that
matches the philosophy of the project.
